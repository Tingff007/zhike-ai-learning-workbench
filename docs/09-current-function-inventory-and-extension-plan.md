# 当前功能盘点与拓展建议

## 1. 文档定位

本文用于沉淀当前项目的基本功能统计、已落地能力清单和后续可拓展方向，便于比赛汇报、阶段验收、后续排期和评审说明使用。

统计口径基于当前仓库中的 README、`docs/` 设计文档、前端路由、后端 API 路由、服务模块、数据模型和测试文件。本文不替代各专项设计文档；涉及页面、API、数据模型和智能体编排的详细契约，仍以对应专项文档为准。

## 3. 已有基本功能清单

### 3.1 账号与权限

- 支持登录、注册、退出登录。
- 支持读取当前用户、修改账号显示名称。
- 支持用户模式与管理员模式切换。
- 管理端通过管理员权限守卫访问。
- WebSocket 和 REST 接口均有认证与课程访问校验。

### 3.2 AI 学习工作台

- `/dashboard` 作为默认 AI 学习入口。
- 支持普通学习对话、通用学习模式和课程学习模式。
- 支持显式课程资料问答模式。
- 支持资源生成快捷入口和资源任务卡片。
- 支持 ArtifactCanvas 资源预览、编辑、保存、版本沉淀。
- 支持会话历史、会话重命名、删除和消息回看。
- 支持 AI 对话 WebSocket 流式输出、停止生成、引用信息和质量信息展示。

### 3.3 意图路由与 AI 编排

- 后端保留统一 `AiOrchestratorService` 入口。
- `HybridIntentRouter` 可识别普通问答、开始学习、学习计划、学习进度查询、课程资料问答和资源生成。
- HTTP 和 WebSocket 共用同一套意图路由与编排逻辑。
- 管理端支持意图路由配置查看、YAML 编辑、校验、评测、发布、回滚、导入、导出和从文件重载。
- 路由结果可写入调用日志和 Trace，便于评测与治理。

### 3.4 课程与课程建设

- 支持课程列表、我的课程、当前课程选择和课程详情。
- 支持管理员创建、编辑、删除、还原和彻底清理课程。
- 支持章节、知识点、前置依赖和课程图谱维护。
- 支持 AI 生成课程结构。
- 支持课程目录导入、预览和应用。
- 支持课程就绪度检查，用于判断课程是否具备对话、资料问答和资源生成条件。

### 3.5 知识大本营与课程资料库

- 支持课程资料上传和上传策略校验。
- 支持 ChatDoc / 云端 RAG 配置与实例管理。
- 支持文档解析、切分、向量化、抽取和状态查询。
- 支持文档原文预览、课程侧资料浏览和文件下载。
- 支持 ChatDoc 切片、原生切片、切片同步、重切分、切片编辑、切片版本还原。
- 支持批量向量化、批量抽取、知识检索和引用治理。
- 支持资料软删除、回收站、还原和彻底删除。

### 3.6 模型网关中心

- 支持 Chat、Embedding、RAG、图片生成等模型供应商配置。
- 支持供应商模板、供应商图标、密钥托管状态、连接测试和草稿测试。
- 支持设置默认供应商、全量健康检查和配置热重载。
- 支持模型调用日志、Trace 详情、日志清理和用量统计。
- 支持课程级 ChatProvider、CloudRagProvider、图片生成供应商和知识库配置绑定。
- 支持 ChatDoc 厂商额度、流水线参数和多实例配置。

### 3.7 学情画像

- 支持全局画像、课程画像、会话画像和跨课程画像。
- 画像维度包含分数、标签、置信度、证据和更新时间。
- 支持画像证据写入、测评证据写入和会话证据沉淀。
- 支持用户纠偏，包括更新维度、标记不准确、隐藏证据和清理证据。
- 可作为学习路径、资源生成和个性化推荐的上下文依据。

### 3.8 学习路径、掌握度与学习事件

- 支持课程学习路径读取和生成。
- 支持路径节点状态更新。
- 支持课程掌握度读取和课程画像读取。
- 支持学习事件记录，评估结果可反哺掌握度和路径节点。
- AI 对话中可通过意图路由读取真实学习进度快照。

### 3.9 练习评估

- 支持费曼阐述、代码实验和自测题单提交。
- 后端可生成评分、Rubric 分项评分、反馈、薄弱原因、补救建议和自然语言学习进度报告。
- 评估结果会写入测评记录、概念掌握度、画像证据和学习事件。
- 评估后可触发学习路径再生成。
- 当前优先使用 ModelGateway ChatProvider 做 LLM Rubric 结构化评分；模型不可用或 JSON 不合法时回退本地结构化 Rubric。

### 3.10 多智能体资源生成

- 支持高白话讲义、思维导图、阶段测评题、错题补救卡、PPT 大纲、代码实验、视频脚本、拓展阅读和教学图解包。
- 资源生成任务包含任务创建、运行、取消、状态查询和进度推送。
- 支持课程资料检索、画像适配、资源正文生成、引用核验、安全审查和版本保存。
- 支持资源生成 WebSocket 进度流；连接后通过 `auth` 帧鉴权，Redis 不可用时可回退数据库轮询。
- 支持真实图片生成供应商配置后生成教学图解包。
- 支持 ArtifactCanvas 本地导出 Markdown、DOCX、PPTX、浏览器打印 PDF，思维导图 SVG / PNG 和图解包单图下载；DOCX / PPTX 已改为使用成熟前端生成库按需生成，不再依赖手写 OOXML。
- 支持 Inspector 按规划、取证、生成、核验、安全、保存展示多智能体工作流概览，并保留 Trace 时间线。

### 3.11 资源大厅与资源生命周期

- 支持课程资源、通用资源、我的资源、社区资源、精选资源和推荐资源聚合展示。
- 支持搜索、筛选、统计、精选、推荐、最近资源等聚合口径。
- 支持结构化推荐解释，按课程匹配、画像匹配、薄弱点、掌握度短板、最近学习事件、引用和质量复用展示推荐证据。
- 支持手动上传资源、资源详情预览、复制资源、删除资源和批量删除。
- 支持资源版本查看和恢复。
- 支持提交社区审核、课程归档和资源复用。
- 资源状态可与审核结果联动。

### 3.12 资源审核

- 支持审核统计、审核队列、审核详情和审核日志。
- 支持通过、精选、要求修改、拒绝、隐藏和归档等审核动作。
- 支持质量分、质量等级、审核意见、标签和安全状态治理。
- 审核结果会影响资源大厅中的社区可见性和精选状态。

### 3.13 公告中心与公告发布

- 用户侧支持公告摘要、公告列表、公告详情、已读、全部已读和关闭。
- 管理端支持公告创建、编辑、发布、归档、删除和统计。
- 公告展示类型覆盖顶部条、弹窗、Toast 和页面卡片。
- 支持按角色、优先级、生效时间和过期时间进行公告治理。

### 3.14 学习日历

- 支持日历视图展示学习安排。
- 支持后端 `learning_schedule_items` 保存真实学习日程，包含日期、状态、来源、课程、路径节点和资源关联。
- 当前前端会聚合已保存日程、学习路径、资源和公告生成日历事件。
- 支持课程模式和通用学习模式下的不同日程提示。
- 支持把系统建议保存为日程，并将已保存日程标记完成或重新计划；完成状态会写入学习事件。提醒推送系统仍可继续扩展。

### 3.15 个人设置

- 支持账号资料展示和显示名称编辑。
- 支持当前课程上下文展示。
- 支持模型连接状态展示。
- 支持学习伙伴偏好选择和悬浮助手显示设置。
- 支持本地学习缓存导出、清理和退出登录。
- 学习伙伴偏好当前以本地前端状态为主。

### 3.16 界面设置

- 管理端支持登录页背景配置。
- 支持图片 / 视频背景媒体上传。
- 支持背景裁切、亮度、遮罩、回退底色和预览。
- 公共接口可读取登录页背景配置。

### 3.17 运维监控

- 支持平台指标、运营看板、趋势数据、模型调用、RAG 报告和成本额度。
- 支持链路健康、云端知识资产漏斗、资源生成失败、AI 对话质量和安全拒答统计。
- 支持告警与事件展示。
- 后端启动时会运行模型网关健康检查、模型配置热重载和资源生成调度器。

## 5. 建议优先级路线

### 第一阶段：完善可演示闭环（已完成）

- 已强化 `/dashboard` 普通对话、课程资料问答和资源生成的稳定性。
- 完善资源导出、资源版本、资源审核和资源大厅联动；其中导出已覆盖 Markdown、DOCX、PPTX、浏览器 PDF 打印、思维导图 SVG / PNG 和图解包单图下载，DOCX / PPTX 已采用成熟生成库实现。
- 已将学习日历补齐为真实可保存日程，支持保存建议事项、读取已保存日程和标记完成。
- 已将练习评估升级为 LLM Rubric 分项评分，返回维度分、证据、改进建议和学习进度报告。

### 第二阶段：突出个性化智能（已完成）

- 已强化画像参与资源生成、学习路径和资源推荐的证据链。
- 已增加推荐解释、薄弱点追踪和学习进度自然语言报告；测评链路返回自然语言进度报告，资源大厅展示结构化推荐证据。
- 已增强课程资料引用核验和低置信度拒答策略。
- 已将多智能体流程做成更清晰的 Trace 与可视化工作流：Inspector 汇总规划、取证、生成、核验、安全、保存节点，并保留原始步骤时间线。

### 第三阶段：扩展教学运营场景（后续）

- 增加教师 / 助教角色与班级管理。
- 增加班级学习分析、资源共享、教学干预和课程运营看板。
- 完善协作学习社区和资源二次创作流程。
- 补齐生产化部署、审计、告警和数据安全能力。

## 6. 当前功能定位总结

当前项目已经具备完整的 AI 个性化学习工作台雏形：以 AI 对话为入口，以课程资料问答和资源生成为核心智能能力，以学习路径、学情画像、练习评估和资源大厅构成学习闭环，并通过知识大本营、网关中心、资源审核、公告发布和运维监控支撑管理端治理。

后续拓展重点不宜只增加零散页面，而应围绕三条主线推进：

1. **学习闭环更真实**：日程可执行、评估更可信、路径可持续更新。
2. **个性化更可解释**：画像、掌握度、资源推荐和生成依据都能追溯。
3. **教学运营更完整**：从个人学习助手扩展为课程、班级和教师都能使用的平台。
