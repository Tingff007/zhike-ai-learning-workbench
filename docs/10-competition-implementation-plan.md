## 一、项目定位

基于智课项目底座，改造为面向**计算机科学与人工智能学科**的**双端口智能教学平台**：

**助学端（学生）**：AI 驱动的个性化学习工作台
**助教端（教师/TA）**：AI 辅助的教学管理工作台

> 两端口共享同一后端底座（学科垂类大模型 + RAG 知识库 + 多智能体引擎）

### 3.3 数据库新增表

`sql
-- 班级表
CREATE TABLE ta_classes (
    id UUID PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    description TEXT,
    course_id UUID REFERENCES courses(id),
    ta_user_id UUID REFERENCES users(id),
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 班级学生关联
CREATE TABLE ta_class_students (
    class_id UUID REFERENCES ta_classes(id),
    student_id UUID REFERENCES users(id),
    joined_at TIMESTAMP DEFAULT NOW(),
    PRIMARY KEY (class_id, student_id)
);

-- 备课记录
CREATE TABLE ta_lesson_plans (
    id UUID PRIMARY KEY,
    title VARCHAR(300),
    content JSONB,        -- 教案结构化内容
    course_id UUID REFERENCES courses(id),
    created_by UUID REFERENCES users(id),
    version INT DEFAULT 1,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 批改记录
CREATE TABLE ta_grading_records (
    id UUID PRIMARY KEY,
    submission_id UUID,
    grader_type VARCHAR(20),  -- 'auto', 'ai_assisted', 'manual'
    score DECIMAL(5,2),
    feedback JSONB,
    created_at TIMESTAMP DEFAULT NOW()
);

-- 学习行为事件
CREATE TABLE student_learning_events (
    id UUID PRIMARY KEY,
    student_id UUID REFERENCES users(id),
    event_type VARCHAR(50), -- 'chat', 'quiz', 'resource_view', 'code_run', etc.
    course_id UUID REFERENCES courses(id),
    metadata JSONB,
    created_at TIMESTAMP DEFAULT NOW()
);

-- 预警记录
CREATE TABLE ta_alert_records (
    id UUID PRIMARY KEY,
    student_id UUID REFERENCES users(id),
    class_id UUID REFERENCES ta_classes(id),
    alert_type VARCHAR(50), -- 'score_drop', 'inactive', 'mastery_gap'
    severity VARCHAR(20),   -- 'low', 'medium', 'high'
    description TEXT,
    resolved BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT NOW()
);
`

## 四、模型微调方案 (LoRA)

### 4.1 推荐方案 (低成本高回报)

| 项目 | 选择 | 理由 |
|------|------|------|
| 基座模型 | **Qwen2.5-7B-Instruct** | 中文能力强、Apache 2.0许可、社区活跃 |
| 微调方式 | **LoRA (r=16, alpha=32)** | 单卡RTX 3090/4090可跑，成本可控 |
| 微调数据 | 计算机科学/AI 教学对话对 (5000-10000条) | 学科问答对+教案生成对+批改推理对 |
| 通用能力 | 保持API调用(Qwen/DeepSeek) | LoRA 专注于学科专业能力增强 |
| 部署方式 | **vLLM 本地部署** 或 API转发 | 根据服务器情况选择 |

### 4.2 微调数据构建策略

`
数据源：
├── 课程教材 (深度学习/机器学习/AI导论PDF→提取Q&A)
├── GitHub 学习资源 (CS自学指南等→知识点提取)
├── 学科经典论文摘要 (Papers We Love)
├── 教学案例 (教案/试题/解答→格式化)
└── 历史对话数据 (智课已有对话日志→清洗)

数据集格式 (Alpaca格式)：
{
    "instruction": "请解释深度学习中的反向传播算法",
    "input": "",
    "output": "反向传播(Backpropagation)是训练神经网络的核心算法... [逐步推导+代码示例+图解说明]"
}
`
